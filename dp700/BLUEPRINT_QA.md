# DP-700 問題道場：公式ガイド準拠の監査基準

対象: https://minetoshi.github.io/dp700/ （リポジトリ `minetoshi/minetoshi.github.io` の `dp700/`）

公式基準: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-700 （2026-10-19版を基準として継続的に確認）

## 問題単位のチェック項目

- [ ] 現行公式ガイドの具体的なスキル項目（subskill）に紐付く
- [ ] 問題文の条件が明確で正答が一意（複数選択では指定個数が正しい）
- [ ] 正答と誤答の理由が現行Fabric仕様に沿い、公式根拠URLがある
- [ ] 誤答選択肢の理由が個別に説明されている
- [ ] SQL / PySpark / KQL等のコード例が構文・意味とも正しい
- [ ] 日本語訳が条件、否定、最適解の判断基準を変えていない
- [ ] 現行の製品名、権限、制限事項、推奨手法に整合する
- [ ] 監査状態（未確認 / 要修正 / 確認済み）を記録する

## カバレッジの監査

- 分析ソリューションの実装と管理: 30–35%
- データの取り込みと変換: 30–35%
- 分析ソリューションの監視と最適化: 30–35%

設問数の割合だけでなく、公式ガイドに記載された各サブスキルを網羅すること。既存ページにある「公式49項目100%対応」は、各項目の実測と根拠を確認するまで監査済みの主張として扱わない。

## 受入条件

1. 既存の問題、PA解説、学習履歴、スマートフォン表示を壊さない。
2. 追加問題は出典、ライセンス、公式ガイド対応スキル、解説を持つ。
3. 既存問題と外部問題を別バンクとして選択できる。
4. 全追加問題について翻訳・正答・選択肢・解説を照合し、手動または自動テストで確認する。
5. 公開前にGitHub Pagesの表示と操作を検証する。
