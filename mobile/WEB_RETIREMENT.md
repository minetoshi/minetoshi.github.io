# Web版を終了する手順

Web版の問題演習は最終的に終了する。現時点では、ネイティブiPhone版の実機確認と履歴移行が完了していないため、`/dp700/` の演習を維持する。

1. ネイティブ版を実機とTestFlightで確認し、署名済みの最終バイナリをApp Storeへ提出・公開する。旧iPhone版の自動移行とWeb版JSONの読み込み・復元を実機で確かめる。
2. Web版のホームに終了予定日と履歴JSONの保存方法を事前に表示する。終了前にWeb版の履歴保存を操作し、iPhone版への読み込みを確認する。利用者に十分な移行期間を設ける。
3. 終了日に `/dp700/` を演習画面から案内ページへ切り替える。案内ページにはアプリへの導線、サポート、プライバシー、履歴JSONを書き出す移行専用ページへのリンクを残す。移行専用ページは既存の `dp700-dojo-v2` ローカルストレージだけを読み、本人が操作した場合にJSONを保存する。問題文・解答は配信しない。
4. アプリの設定画面からWeb版へ向かうリンクを案内ページへ合わせ、履歴移行の操作を再検証する。サポートURLとプライバシーURLは停止しない。
5. GitHub Pagesから問題配信ファイルを外した後も、公開Git履歴と既存クローンにデータは残る。非公開化の保証やアクセス制限として扱わない。新しい販売専用問題は非公開の管理元で作る。

終了予定日と移行期間は、実機とApp Store公開の結果を見て決める。Web版の履歴と公開URLを予告なく消さない。
